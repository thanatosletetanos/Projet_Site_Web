# Projet : Site Web
Sujet libre : Garage Hot Wheels 
Ce projet a été réalisé dans le cadre du cours de 'Web: Principe De Base'.
Il s'agit d'un site vitrine présentant une partie de ma collection.
---
## Objectifs du projet
Utiliser **HTML** et **CSS**
Mettre en place plusieurs pages reliées par une barre de navigation
Respecter les balises sémantiques HTML (header, nav, main, section, article, footer, aside)
Appliquer une mise en mage moderne avec **Flexbox** et **CSS Grid**
Rendre le site **responsive** grâce aux media queries
Intégrer un formulaire de contact fonctionnel (non relié à un backend)
---
## Structure du site
Le site contient **5 pages** :
'index.html' - Page d'accueil
'collection.html' - Présentation de plusieurs modèles Hot Wheels
'favorites.html' - A propos du projet
'contact.html' - Formulaire de contact

Un fichier CSS externe se dans 'css/style.css'
Les images sont regroupées dans 'ImagesHT/'
---
## Responsive
Le site s'adapte aux différentes tailles d'écran grâce à plusieurs breakpoints :
Mobile
Tablette / petit écran
Desktop

La navigation s'ajuste automatiquement selon la largeur de l'écran.
