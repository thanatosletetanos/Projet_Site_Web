# Projet : Site Web
Sujet libre : Garage Hot Wheels 
Ce projet a été réalisé dans le cadre du cours de 'Web: Principe De Base'.
Il s'agit d'un site vitrine présentant une partie de ma collection.
---
## Objectifs du projet
- L'utilisation **HTML** & **CSS**
- Relier les pages entre elle avec une barre de navigation
- Le respect des balises sémantiques HTML (header, nav, main, section, article, footer, aside)
- L'utilisation de **Flexbox** & **CSS Grid**
- Rendre le site **responsive** grâce aux media queries
- Créer un formulaire fonctionnel 
---
## Structure du site
Le site contient **5 pages** :
- 'index.html' - Page d'accueil
- 'collection.html' - Présentation de plusieurs modèles Hot Wheels
- 'about.html' - A propos du projet
- 'favorites.html' - Mes modèles préférés et ce que que je recherche 
- 'contact.html' - Formulaire de contact

Un fichier CSS externe se dans 'css/style.css'
Les images sont regroupées dans 'ImagesHT/'
Une police qui se retrouve dans 'fonts/' (libre d'utilisation)
---
## Responsive
Le site s'adapte aux différentes tailles d'écran grâce à plusieurs breakpoints :
- Mobile
- Tablette 
- Desktop

La navigation s'ajuste automatiquement selon la largeur de l'écran.
---
## Détail
J'ai eu l'idée de faire ce site grâce à l'app de Mattel qu'ils ont sorti il n'y a pas longtemps. 
C'est une app qui se nomme 'HW Showcase' et elle permet de regroupé notre collection en ligne, 
il y a aussi une partie où nous pouvons découvrir les derniers modèles et les modèles plus rares.
